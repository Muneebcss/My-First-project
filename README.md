# TaskBridge — Service Marketplace Website

A small, responsive, Fiverr-inspired **static website** made with HTML, CSS, and a little JavaScript for a beginner GitHub assignment.

## Pages
- `index.html` — Home page
- `services.html` — Service categories
- `contact.html` — Contact form and privacy policy
- `style.css` — Shared responsive styling
- `script.js` — Demo-only contact form behavior

## Run locally
1. Download or extract this folder.
2. Open the folder in Visual Studio Code.
3. Open `index.html` in your browser, or use the VS Code Live Server extension.
4. Use the navigation links to test all three pages.

## Publish with GitHub Pages
1. Create a GitHub repository, for example `taskbridge-website`.
2. In VS Code, open **Terminal → New Terminal** in this folder.
3. Run the commands below, replacing `YOUR-USERNAME` with your GitHub username if using the HTTPS remote:

```bash
git init
git add .
git commit -m "Create TaskBridge website"
git branch -M main
git remote add origin https://github.com/YOUR-USERNAME/taskbridge-website.git
git push -u origin main
```

4. On GitHub, open the repository → **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Choose branch `main` and folder `/(root)`, then click **Save**.
7. Wait for GitHub Pages to publish the site. The website URL will be shown in the Pages settings.

If Git says your identity is not configured, set it with your own details:

```bash
git config --global user.name "Your Name"
git config --global user.email "your-email@example.com"
```

## Important
This is a learning demo, not a real marketplace. The contact form does not transmit or save data. There is no account system, database, payment handling, or real freelancer booking.
